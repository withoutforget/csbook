# Теория множеств: от аксиом до SQL

## Введение

Теория множеств — математическая дисциплина, изучающая множества и операции над ними. Созданная Георгом Кантором в 1870–1880-х годах, она стала фундаментом всей современной математики. Для программиста теория множеств имеет непосредственное практическое значение: реляционные базы данных основаны на ней, структуры данных описываются через неё, а понимание её аксиом помогает избежать ряда хитрых ошибок.

---

## 1. Наивная теория множеств и её проблемы

В наивной теории множеств принимается, что для любого свойства $P$ можно построить множество всех объектов, обладающих этим свойством: $\{x \mid P(x)\}$.

Это удобно, но ведёт к противоречию — **парадоксу Рассела** (1901): рассмотрим множество $R = \{x \mid x \notin x\}$ — множество всех множеств, не являющихся своими собственными элементами. Тогда:

- Если $R \in R$, то $R \notin R$ (по определению $R$)
- Если $R \notin R$, то $R \in R$ (по определению $R$)

Это противоречие показало необходимость аксиоматизации.

## 2. Аксиомы ZFC

Аксиоматическая система Цермело–Френкеля с аксиомой выбора (ZFC) — стандартный фундамент современной математики. Перечислим ключевые аксиомы с пояснениями.

### Аксиома экстенсиональности

Два множества равны тогда и только тогда, когда они содержат одни и те же элементы:

$$A = B \;\leftrightarrow\; (\forall x:\; x \in A \leftrightarrow x \in B)$$

**Программная аналогия**: множество определяется своими элементами, не порядком или дублированием. $\{1, 2, 3\}$ и $\{3, 1, 2\}$ — одно множество. В Python:

```python
s1 = {1, 2, 3}
s2 = {3, 1, 2, 1}
print(s1 == s2)  # True — одни и те же элементы
```

### Аксиома пустого множества

Существует множество, не содержащее элементов: $\varnothing$.

```python
empty = set()
print(len(empty))  # 0
```

### Аксиома пары

Для любых $x$ и $y$ существует множество $\{x, y\}$.

### Аксиома объединения

Для любого семейства множеств существует множество — объединение всех:

```python
family = [{1, 2}, {2, 3}, {4}]
union = set.union(*family)  # {1, 2, 3, 4}
```

### Аксиома степени (множества всех подмножеств)

Для любого множества $A$ существует его степень $2^A$ — множество всех подмножеств.

```python
def power_set(s):
    lst = list(s)
    n = len(lst)
    result = []
    for i in range(2**n):
        subset = {lst[j] for j in range(n) if i & (1 << j)}
        result.append(subset)
    return result

print(power_set({1, 2, 3}))
# [{}, {1}, {2}, {1,2}, {3}, {1,3}, {2,3}, {1,2,3}]
```

Если $|A| = n$, то $|2^A| = 2^n$. Это объясняет, почему биты в байте представляют $2^8 = 256$ значений.

### Аксиома бесконечности

Существует бесконечное множество (натуральные числа $\mathbb{N}$).

### Аксиома выбора (AC)

Для любой семьи непустых непересекающихся множеств существует множество, содержащее ровно по одному элементу из каждого.

Аксиома выбора эквивалентна ряду важных утверждений: лемме Цорна, теореме Тихонова о произведении компактных пространств, принципу трихотомии для кардиналов.

## 3. Операции над множествами

### Основные операции

```python
A = {1, 2, 3, 4, 5}
B = {3, 4, 5, 6, 7}

# Объединение (A ∪ B)
print(A | B)        # {1, 2, 3, 4, 5, 6, 7}
print(A.union(B))   # то же самое

# Пересечение (A ∩ B)
print(A & B)           # {3, 4, 5}
print(A.intersection(B))

# Разность (A \ B)
print(A - B)           # {1, 2}
print(A.difference(B))

# Симметрическая разность (A △ B = (A∪B) \ (A∩B))
print(A ^ B)              # {1, 2, 6, 7}
print(A.symmetric_difference(B))

# Включение (A ⊆ B)
print({1, 2}.issubset({1, 2, 3}))  # True
print({1, 2} <= {1, 2, 3})         # True

# Строгое включение (A ⊂ B)
print({1, 2} < {1, 2, 3})          # True
print({1, 2} < {1, 2})             # False
```

### Декартово произведение

Декартово произведение $A \times B$ — множество всех упорядоченных пар $(a, b)$, где $a \in A$, $b \in B$:

```python
from itertools import product

A = {1, 2}
B = {'a', 'b', 'c'}
cartesian = set(product(A, B))
print(cartesian)
# {(1,'a'), (1,'b'), (1,'c'), (2,'a'), (2,'b'), (2,'c')}
print(len(cartesian))  # 6 = |A| × |B| = 2 × 3
```

Декартово произведение — это формальная основа реляционных таблиц. Таблица в SQL — это конечное подмножество декартова произведения доменов (множества допустимых значений) столбцов.

## 4. Теория множеств и реляционные базы данных

Реляционная модель данных, предложенная Эдгаром Коддом в 1970 году, непосредственно основана на теории множеств. Понимание этой связи объясняет многие свойства SQL.

### Отношение как множество

Таблица в реляционной БД — это **отношение**: конечное множество кортежей (строк). Каждый кортеж — элемент декартова произведения доменов:

$$\text{Employees} \subseteq \mathbb{N} \times \text{String} \times \mathbb{N} \times \text{String}$$

Поскольку таблица — множество, в ней по определению не должно быть дублирующихся строк (хотя SQL допускает мультимножества, что является отступлением от реляционной теории).

### SQL-операции как множественные

| SQL | Теория множеств |
|---|---|
| `UNION` | $A \cup B$ |
| `INTERSECT` | $A \cap B$ |
| `EXCEPT` | $A \setminus B$ |
| `JOIN` | Специализированное декартово произведение |
| `WHERE` | Выбор подмножества |
| `SELECT` | Проекция (отображение) |

```sql
-- Объединение: все города из обеих таблиц
SELECT city FROM customers
UNION
SELECT city FROM suppliers;

-- UNION ALL сохраняет дубликаты (мультимножество, не множество!)
SELECT city FROM customers
UNION ALL
SELECT city FROM suppliers;
```

### Закрытость операций

Ключевое свойство реляционной алгебры: результат операции над отношениями — снова отношение. Это обеспечивает **замкнутость** — возможность вкладывать операции:

```sql
-- Вложенные запросы — это прямое следствие замкнутости
SELECT * FROM (
    SELECT * FROM employees WHERE department = 'Engineering'
) eng
WHERE salary > 50000;
```

## 5. Кардинальные числа и счётность

Два множества имеют одинаковую мощность (кардинальное число), если между ними можно установить взаимнооднозначное соответствие (биекцию).

### Счётные и несчётные множества

**Счётные множества** — те, между которыми и $\mathbb{N}$ можно установить биекцию:
- Натуральные числа $\mathbb{N} = \{0, 1, 2, 3, \ldots\}$
- Целые числа $\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$
- Рациональные числа $\mathbb{Q}$ (биекция строится диагональным методом Кантора)

**Несчётные множества** (строго большей мощности):
- Действительные числа $\mathbb{R}$
- Все функции $\mathbb{N} \to \{0, 1\}$

Канторовская диагональ (1891) доказывает несчётность $\mathbb{R}$. Предположим, что все числа в $(0, 1)$ перечислены: $a_1, a_2, a_3, \ldots$ Строим новое число $b$, чья $i$-я цифра отличается от $i$-й цифры $a_i$. Тогда $b$ не совпадает ни с одним $a_i$ — противоречие.

### Следствие для программирования

Программ (конечных текстов над конечным алфавитом) — счётное число. Функций $\mathbb{N} \to \mathbb{N}$ — несчётное. Значит, большинство функций **невычислимы** — им не соответствует никакая программа.

## 6. Ординальные числа

Кардинальные числа измеряют **размер** множества. Ординальные числа описывают **порядок** — типы упорядоченных множеств.

Конечные ординалы совпадают с натуральными числами. Первый бесконечный ординал $\omega$ — тип упорядочения $\{0, 1, 2, \ldots\}$. За ним идут $\omega+1, \omega+2, \ldots, \omega \cdot 2, \omega^2, \ldots$

Ординальные числа важны в теории сложности: они используются для доказательства завершаемости алгоритмов (well-founded induction) — если удаётся показать, что некоторая «мера» алгоритма строго убывает при каждом шаге, то алгоритм завершается.

## 7. Частичные порядки и решётки

Частичный порядок $\leq$ на множестве $L$ — рефлексивное, антисимметричное, транзитивное отношение.

**Решётка** — частично упорядоченное множество, в котором для любых двух элементов $a, b$ существуют:
- $\sup(a, b)$ — наименьшая верхняя грань (join, $\sqcup$)
- $\inf(a, b)$ — наибольшая нижняя грань (meet, $\sqcap$)

Решётки встречаются повсюду в CS:
- **Булева алгебра** — решётка с операциями $\land$, $\lor$
- **Тип-решётки** в системах типов: тип Any — наивысший, Never — наинизший
- **Анализ потоков данных** в компиляторах использует решётки для монотонного вычисления фиксированных точек

```python
# Решётка подмножеств: ⊆ — частичный порядок
# join = union, meet = intersection
A = {1, 2}
B = {2, 3}
join = A | B  # {1, 2, 3} — наименьшее множество, содержащее оба
meet = A & B  # {2} — наибольшее множество, содержащееся в обоих
```

### Теорема Тарского–Кнастера

Для полной решётки $L$ и монотонной функции $f: L \to L$ (то есть $x \leq y \Rightarrow f(x) \leq f(y)$) существует наименьшая неподвижная точка: $f(x) = x$.

Эта теорема лежит в основе семантики рекурсивных программ и анализа потоков данных:

```python
# Достижимые состояния программы вычисляются как наименьшая неподвижная точка
def compute_reachable(initial_state, transition):
    reachable = {initial_state}
    while True:
        new_states = set()
        for state in reachable:
            new_states.update(transition(state))
        if new_states <= reachable:  # неподвижная точка
            break
        reachable |= new_states
    return reachable
```

## 8. Мультимножества и применения

Мультимножество (bag) позволяет элементам повторяться. В отличие от множества, $\{1, 1, 2\} \neq \{1, 2\}$ для мультимножества.

```python
from collections import Counter

# Counter реализует мультимножество
bag1 = Counter([1, 1, 2, 3])
bag2 = Counter([1, 2, 2, 3])

# Сумма мультимножеств
print(bag1 + bag2)   # Counter({1: 3, 2: 3, 3: 2})

# Пересечение — min по каждому элементу
print(bag1 & bag2)   # Counter({1: 1, 2: 1, 3: 1})

# Объединение — max по каждому элементу
print(bag1 | bag2)   # Counter({1: 2, 2: 2, 3: 1})
```

SQL с `UNION ALL` работает с мультимножествами. `UNION` же — с множествами (удаляет дубликаты, что дороже по времени).

## 9. Нечёткая теория множеств

Классическая теория множеств бинарна: элемент либо принадлежит, либо нет. Нечёткая теория множеств (Лотфи Заде, 1965) допускает степень принадлежности от 0 до 1.

Нечёткое множество $A$ на универсуме $X$: $A = \{(x,\, \mu_A(x)) \mid x \in X\}$, где $\mu_A(x) \in [0, 1]$.

```python
def tall(height_cm):
    """Степень принадлежности к нечёткому множеству 'высокий'"""
    if height_cm < 160:
        return 0.0
    elif height_cm > 190:
        return 1.0
    else:
        return (height_cm - 160) / 30

print(tall(175))  # 0.5 — умеренно высокий
print(tall(190))  # 1.0 — определённо высокий
```

Нечёткие множества используются в системах управления (нечёткий регулятор), обработке естественного языка и системах принятия решений.

## Заключение

Теория множеств — не просто абстрактная математика. Она:

- **Основа реляционных БД**: таблицы — это отношения (множества кортежей), SQL — реляционная алгебра над ними
- **Основа структур данных**: Set, Map, List — все описываются через множества
- **Основа теории типов**: типы — это множества значений
- **Объясняет невычислимость**: несчётность функций vs счётность программ

Понимание теории множеств превращает интуитивное «это работает» в строгое «это работает потому, что...». Именно эта строгость нужна при проектировании сложных систем и доказательстве их корректности.

# Дискретная математика: комбинаторика, отношения, доказательства

## Введение

Дискретная математика — это раздел математики, изучающий объекты, которые принимают конечное или счётное число значений. В отличие от непрерывного анализа, где функции плавно меняются, дискретная математика оперирует чёткими, разделёнными элементами: числами, графами, множествами, логическими высказываниями. Именно поэтому она является фундаментом информатики: компьютер по своей природе — дискретная машина, он работает с битами, а не с непрерывными величинами.

Изучение дискретной математики даёт разработчику язык, на котором можно точно формулировать задачи, доказывать корректность алгоритмов, анализировать их сложность и проектировать надёжные системы. Без базового понимания дискретной математики невозможно по-настоящему понять, почему определённые алгоритмы работают быстрее других, как устроены реляционные базы данных, или почему некоторые задачи принципиально неразрешимы за разумное время.

## 1. Теория множеств: основа всего

Всё в математике строится на понятии множества. Множество — это неупорядоченная коллекция различных объектов, называемых элементами. Запись `x ∈ A` означает «x является элементом множества A», запись `x ∉ A` — обратное.

### Основные операции над множествами

| Операция | Обозначение | Смысл |
|---|---|---|
| Объединение | A ∪ B | Все элементы, входящие в A или B |
| Пересечение | A ∩ B | Элементы, входящие одновременно в A и B |
| Разность | A \ B | Элементы A, не входящие в B |
| Дополнение | Ā | Все элементы, не входящие в A |
| Декартово произведение | A × B | Множество всех пар (a, b) |

Именно эти операции лежат в основе SQL. Оператор `UNION` — это объединение результатов двух запросов. `INTERSECT` — пересечение. `EXCEPT` — разность. Понимание теории множеств сразу объясняет семантику этих операторов.

```sql
-- Объединение: все пользователи из России или США
SELECT id FROM users WHERE country = 'RU'
UNION
SELECT id FROM users WHERE country = 'US';

-- Пересечение: пользователи, у которых есть и заказ, и профиль
SELECT user_id FROM orders
INTERSECT
SELECT user_id FROM profiles;
```

### Мощность множества и счётность

Мощность (кардинальное число) множества — это количество его элементов. Конечное множество `{a, b, c}` имеет мощность 3. Бесконечные множества бывают счётными (можно установить взаимнооднозначное соответствие с натуральными числами) и несчётными.

Канторовская теорема доказывает, что мощность множества всех подмножеств A (степень множества, `2^|A|`) всегда строго больше мощности самого A. Именно поэтому количество возможных состояний n бит равно 2^n — это мощность множества всех подмножеств из n элементов.

## 2. Комбинаторика: считаем правильно

Комбинаторика изучает методы подсчёта числа конфигураций, отвечающих заданным условиям. Для разработчика это особенно важно: анализ сложности алгоритмов часто сводится к подсчёту числа возможных случаев.

### Правило произведения и правило суммы

**Правило произведения**: если действие A можно выполнить m способами, а действие B — n способами, и они независимы, то последовательность (A, затем B) можно выполнить m × n способами.

**Правило суммы**: если действие A можно выполнить m способами, а действие B — n способами, и они взаимоисключающие, то одно из двух действий можно выполнить m + n способами.

```python
# Пример: сколько паролей длиной 8 символов из a-z и 0-9?
import string
alphabet = string.ascii_lowercase + string.digits  # 36 символов
password_count = 36 ** 8  # правило произведения
print(f"Количество паролей: {password_count:,}")  # 2,821,109,907,456
```

### Перестановки

Перестановка — это упорядоченное расположение элементов. Число перестановок n различных элементов: `P(n) = n!`

Число перестановок из n элементов по k (без повторений): `P(n, k) = n! / (n - k)!`

```python
from math import factorial

def permutations(n, k):
    return factorial(n) // factorial(n - k)

# Сколькими способами можно расставить 5 книг на 3 места?
print(permutations(5, 3))  # 60
```

### Сочетания

Сочетание — это выбор k элементов из n без учёта порядка. Биномиальный коэффициент:

```
C(n, k) = n! / (k! × (n-k)!)
```

Это число называется «n выбрать k» и встречается в биномиальном разложении `(a + b)^n = Σ C(n,k) × a^k × b^(n-k)`.

```python
from math import comb

# Сколько различных команд из 3 человек можно составить из группы 10?
print(comb(10, 3))  # 120

# Треугольник Паскаля: каждая строка — строка биномиальных коэффициентов
for n in range(6):
    row = [comb(n, k) for k in range(n + 1)]
    print(row)
```

### Принцип включений-исключений

Для подсчёта мощности объединения нескольких множеств используется формула:

```
|A ∪ B| = |A| + |B| - |A ∩ B|
|A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|
```

**Практический пример**: подсчитаем, сколько чисел от 1 до 100 делится на 2 или 3.

```python
total = 0
for i in range(1, 101):
    if i % 2 == 0 or i % 3 == 0:
        total += 1

# Теоретически:
div2 = 100 // 2   # 50
div3 = 100 // 3   # 33
div6 = 100 // 6   # 16
theoretical = div2 + div3 - div6  # 67

print(total, theoretical)  # 67 67
```

### Принцип Дирихле (ящиков)

Если n + 1 объектов разложить по n ящикам, то в хотя бы одном ящике окажется не менее двух объектов. Это очевидное утверждение имеет мощные следствия.

**Пример**: среди любых 13 человек обязательно найдутся двое, родившихся в одном месяце (так как месяцев всего 12).

В программировании этот принцип объясняет, почему коллизии в хеш-таблицах **неизбежны**: если у нас n возможных хешей и мы хотим сохранить больше n элементов, гарантированно возникнут коллизии.

## 3. Отношения

Бинарное отношение R между множествами A и B — это подмножество декартова произведения A × B. Если (a, b) ∈ R, пишем aRb.

### Свойства отношений

Отношение R на множестве A может обладать следующими свойствами:

- **Рефлексивность**: ∀a ∈ A: aRa (каждый элемент связан с собой)
- **Симметричность**: aRb ⟹ bRa
- **Антисимметричность**: aRb ∧ bRa ⟹ a = b
- **Транзитивность**: aRb ∧ bRc ⟹ aRc

### Отношения эквивалентности

Рефлексивное + симметричное + транзитивное отношение называется отношением эквивалентности. Оно разбивает множество на классы эквивалентности — непересекающиеся подмножества, объединение которых даёт всё множество.

**Пример**: отношение «иметь одинаковый остаток от деления на n» является отношением эквивалентности на множестве целых чисел. Классы эквивалентности — это {0, n, 2n, ...}, {1, n+1, 2n+1, ...}, и т.д. Это и есть модулярная арифметика — основа хеш-таблиц и криптографии RSA.

```python
# Классы эквивалентности по модулю 5
n = 5
classes = {}
for i in range(20):
    key = i % n
    classes.setdefault(key, []).append(i)

print(classes)
# {0: [0, 5, 10, 15], 1: [1, 6, 11, 16], 2: [2, 7, 12, 17], ...}
```

### Отношения порядка

Рефлексивное + антисимметричное + транзитивное отношение называется частичным порядком. Если при этом любые два элемента сравнимы, это линейный (полный) порядок.

Частичный порядок имеет прямое применение в планировании задач: топологическая сортировка задач с зависимостями — это нахождение линейного расширения частичного порядка.

## 4. Теория графов

Граф G = (V, E) — это пара: множество вершин V и множество рёбер E ⊆ V × V. Граф — одна из наиболее универсальных абстракций в программировании.

### Базовые определения

- **Ориентированный граф (орграф)**: рёбра имеют направление
- **Взвешенный граф**: каждому ребру приписан вес
- **Путь**: последовательность вершин, в которой каждые две соседние соединены ребром
- **Цикл**: путь, начинающийся и заканчивающийся в одной вершине
- **Дерево**: связный граф без циклов

### Применения графов

| Задача | Графовая модель |
|---|---|
| Маршрутизация в сети | Взвешенный граф, Dijkstra |
| Зависимости пакетов | Ориентированный граф, топологическая сортировка |
| Социальные сети | Граф «дружбы», анализ кластеров |
| Git | Ориентированный ациклический граф (DAG) коммитов |
| Компилятор | Граф потока управления (CFG) |

```python
from collections import defaultdict, deque

class Graph:
    def __init__(self):
        self.adj = defaultdict(list)
    
    def add_edge(self, u, v):
        self.adj[u].append(v)
    
    def bfs(self, start):
        visited = set()
        queue = deque([start])
        visited.add(start)
        result = []
        
        while queue:
            node = queue.popleft()
            result.append(node)
            for neighbor in self.adj[node]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)
        
        return result

g = Graph()
g.add_edge(1, 2); g.add_edge(1, 3); g.add_edge(2, 4)
print(g.bfs(1))  # [1, 2, 3, 4]
```

### Эйлеровы и Гамильтоновы пути

Эйлеров путь — путь, проходящий по каждому ребру ровно один раз. Он существует тогда и только тогда, когда связный граф имеет не более двух вершин нечётной степени. Задача о Кёнигсбергских мостах, с которой началась теория графов, не имела решения именно потому, что все четыре вершины имели нечётную степень.

Гамильтонов путь — путь, проходящий через каждую вершину ровно один раз. Задача его поиска является NP-полной — для неё не известно эффективного алгоритма.

## 5. Методы доказательства

Доказательство — это формальная демонстрация истинности утверждения исходя из аксиом и ранее доказанных теорем. Знание методов доказательства важно для верификации алгоритмов.

### Прямое доказательство

Из посылок выводим следствие цепочкой логических шагов.

**Теорема**: Сумма двух чётных чисел чётна.

**Доказательство**: Пусть a = 2m и b = 2n для некоторых целых m, n. Тогда a + b = 2m + 2n = 2(m + n). Так как m + n — целое число, то a + b чётно. ∎

### Доказательство от противного (reductio ad absurdum)

Предполагаем, что утверждение ложно, и приходим к противоречию.

**Теорема**: √2 иррационально.

**Доказательство**: Предположим, что √2 = p/q, где p и q — взаимно простые целые числа (несократимая дробь). Тогда 2 = p²/q², значит p² = 2q², то есть p² чётно. Следовательно, p чётно: p = 2k. Тогда (2k)² = 2q², то есть 4k² = 2q², откуда q² = 2k², значит q² чётно, следовательно q чётно. Но тогда и p, и q чётны — противоречие с тем, что дробь несократима. ∎

### Метод математической индукции

Для доказательства утверждения P(n) для всех натуральных n:
1. **База**: доказываем P(1) (или P(0))
2. **Шаг индукции**: доказываем, что из P(k) следует P(k+1)

**Теорема**: 1 + 2 + ... + n = n(n+1)/2.

**Доказательство**:
- **База**: n = 1: левая часть = 1, правая = 1·2/2 = 1. Верно.
- **Шаг**: Предположим, что 1 + 2 + ... + k = k(k+1)/2. Нужно показать, что 1 + 2 + ... + k + (k+1) = (k+1)(k+2)/2.

  Левая часть = k(k+1)/2 + (k+1) = (k+1)(k/2 + 1) = (k+1)(k+2)/2. ∎

Индукция в программировании — это не просто теоретический инструмент. Именно она используется для доказательства корректности рекурсивных алгоритмов: база соответствует базовому случаю рекурсии, а шаг индукции — рекурсивному случаю.

### Метод счётного аргумента (доказательство через подсчёт)

Считаем одно и то же двумя способами и приравниваем результаты. Этот метод особенно изящен.

**Теорема**: В графе G = (V, E) сумма степеней всех вершин равна 2|E|.

**Доказательство**: Подсчитаем количество пар (вершина, смежное ребро). С одной стороны, для каждой вершины v это deg(v), значит сумма равна Σ deg(v). С другой стороны, каждое ребро вносит вклад 2 (оно инцидентно двум вершинам), значит сумма равна 2|E|. ∎

Следствие: в любом графе число вершин нечётной степени чётно. Именно это условие используется при проверке существования Эйлерова пути.

## 6. Рекуррентные соотношения

Рекуррентное соотношение определяет последовательность через её предыдущие элементы. Это математическая основа анализа рекурсивных алгоритмов.

### Числа Фибоначчи

```
F(0) = 0, F(1) = 1
F(n) = F(n-1) + F(n-2)
```

Наивная рекурсивная реализация имеет экспоненциальную сложность O(2^n). Мемоизация снижает её до O(n).

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

# Или итеративно за O(n) времени и O(1) памяти:
def fib_iterative(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

### Теорема Мастера

Для рекуррентностей вида T(n) = aT(n/b) + f(n), где a ≥ 1, b > 1:

- Если f(n) = O(n^(log_b(a) - ε)), то T(n) = Θ(n^log_b(a))
- Если f(n) = Θ(n^log_b(a)), то T(n) = Θ(n^log_b(a) · log n)
- Если f(n) = Ω(n^(log_b(a) + ε)), то T(n) = Θ(f(n))

**Пример**: Merge Sort: T(n) = 2T(n/2) + O(n). Здесь a = 2, b = 2, f(n) = n. log_2(2) = 1, f(n) = Θ(n^1). Это второй случай, поэтому T(n) = Θ(n log n).

## 7. Булева алгебра и логика высказываний

Булева алгебра — алгебраическая система, в которой элементы принимают одно из двух значений: 0 (ложь) или 1 (истина). Операции: AND (∧), OR (∨), NOT (¬).

### Законы булевой алгебры

```
Идемпотентность:    a ∧ a = a,      a ∨ a = a
Коммутативность:    a ∧ b = b ∧ a,  a ∨ b = b ∨ a
Ассоциативность:    (a ∧ b) ∧ c = a ∧ (b ∧ c)
Дистрибутивность:   a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)
Законы де Моргана:  ¬(a ∧ b) = ¬a ∨ ¬b
                    ¬(a ∨ b) = ¬a ∧ ¬b
```

Законы де Моргана критически важны для оптимизации SQL запросов: `NOT (A AND B)` эквивалентно `NOT A OR NOT B`.

### Нормальные формы

Любое булево выражение можно представить в двух нормальных формах:

- **КНФ (конъюнктивная нормальная форма)**: конъюнкция клоз (дизъюнкций)
- **ДНФ (дизъюнктивная нормальная форма)**: дизъюнкция конъюнктов

KNF используется в алгоритмах решения задачи выполнимости (SAT). Задача SAT — одна из первых задач, доказанных NP-полными (теорема Кука-Левина, 1971).

## 8. Функции и их свойства

Функция f: A → B — это отображение, сопоставляющее каждому элементу из A ровно один элемент из B. В программировании это понятие формализует «чистые функции» (pure functions) — функции без побочных эффектов.

### Инъекция, сюръекция, биекция

- **Инъекция (injection)**: разные элементы A отображаются в разные элементы B (f(a₁) = f(a₂) ⟹ a₁ = a₂)
- **Сюръекция (surjection)**: каждый элемент B имеет прообраз (∀b ∈ B ∃a ∈ A: f(a) = b)
- **Биекция (bijection)**: и инъекция, и сюръекция — взаимнооднозначное соответствие

Биекция важна для хеш-функций: идеальная хеш-функция — это биекция из множества входов в множество хеш-значений. Если хеш-функция не является инъекцией, возникают коллизии.

## 9. Числа: натуральные, целые, рациональные, действительные

Разные числовые системы соответствуют разным типам данных в программировании:

| Математика | Программирование |
|---|---|
| Натуральные числа ℕ | uint32, size_t |
| Целые числа ℤ | int32, int64 |
| Рациональные числа ℚ | Fraction (точная арифметика) |
| Действительные числа ℝ | float32, float64 (приближение!) |

Ключевое понимание: числа с плавающей точкой (float) — это **не** действительные числа. Они представляют конечное подмножество рациональных чисел. Именно поэтому `0.1 + 0.2 ≠ 0.3` в большинстве языков программирования.

```python
print(0.1 + 0.2)        # 0.30000000000000004
print(0.1 + 0.2 == 0.3) # False

from fractions import Fraction
a = Fraction(1, 10)
b = Fraction(2, 10)
print(a + b == Fraction(3, 10))  # True — точная арифметика
```

## 10. Применение дискретной математики в разработке

### Хеш-таблицы

Хеш-таблица использует хеш-функцию h: K → {0, ..., m-1} для отображения ключей в индексы массива. По принципу Дирихле, при числе ключей > m коллизии неизбежны. Хорошая хеш-функция обеспечивает равномерное распределение ключей.

```python
# Полиномиальный хеш строк — классика комбинаторики
def polynomial_hash(s, base=31, mod=10**9 + 7):
    h = 0
    power = 1
    for c in s:
        h = (h + (ord(c) - ord('a') + 1) * power) % mod
        power = (power * base) % mod
    return h
```

### Деревья и рекурсия

Дерево — граф без циклов. Бинарное дерево высоты h содержит не более 2^(h+1) - 1 вершин. Рекурсивный обход дерева — прямое следствие метода математической индукции.

### Топологическая сортировка

Для ориентированного ациклического графа (DAG) задача расстановки вершин в порядке, уважающем направление рёбер — это топологическая сортировка. Алгоритм Кана использует свойства частичного порядка:

```python
from collections import deque, defaultdict

def topological_sort(vertices, edges):
    in_degree = {v: 0 for v in vertices}
    adj = defaultdict(list)
    
    for u, v in edges:
        adj[u].append(v)
        in_degree[v] += 1
    
    queue = deque([v for v in vertices if in_degree[v] == 0])
    result = []
    
    while queue:
        node = queue.popleft()
        result.append(node)
        for neighbor in adj[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
    
    return result if len(result) == len(vertices) else []  # пустой список = есть цикл

# Зависимости пакетов: A нужен до B и C, B нужен до D
vertices = ['A', 'B', 'C', 'D']
edges = [('A', 'B'), ('A', 'C'), ('B', 'D')]
print(topological_sort(vertices, edges))  # ['A', 'C', 'B', 'D'] или ['A', 'B', 'C', 'D']
```

## Заключение

Дискретная математика — это не абстрактная наука ради науки. Каждый её раздел имеет прямое отображение на реальные задачи в разработке:

- **Комбинаторика** → анализ сложности алгоритмов, оценка числа случаев
- **Теория множеств** → реляционные базы данных, языки запросов
- **Теория графов** → маршрутизация, зависимости, социальные сети
- **Логика** → булевы индексы в БД, оптимизация запросов, схемотехника
- **Методы доказательства** → верификация алгоритмов, доказательство корректности

Понимание дискретной математики позволяет не просто использовать готовые алгоритмы, но и создавать новые, доказывать их корректность и предсказывать поведение. Это тот базис, который отделяет инженера, понимающего, почему код работает, от того, кто просто умеет его писать.
